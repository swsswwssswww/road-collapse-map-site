# 道路陥没マップ

公開サイト: https://swsswwssswww.github.io/road-collapse-map-site/

国土交通省などの公開資料をもとに、全国の道路陥没33,301件を発生場所・規模・原因・出典から調べる地図です。政府機関の公式サイトではありません。

このリポジトリは Web 配信用ファイルのみを管理します。HTML に `noindex, nofollow` を設定していますが、アクセス制限はありません。

地点は住所の代表位置を含み、記録の分布は危険度を表しません。出典照合は転記・ファイル整合性の確認であり、現場の事実性を保証するものではありません。

## 配信とバージョン

初期公開版: `v1.0.0`（収集時点 2026-10-22）。

配信する版は `release.json` で指定し、アーカイブの SHA-256 確認後に GitHub Actions で Pages へ配信します。更新時は新しい `website-vX.Y.Z.zip` と `release.json` をコミットします。過去の版へ戻すときは `release.json` を対応するアーカイブ名・ハッシュへ戻します。
