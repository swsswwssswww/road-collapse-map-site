# 道路陥没マップ

公開サイト: https://swsswwssswww.github.io/road-collapse-map-site/

国土交通省などの公開資料に基づく全国の道路陥没33,301件と個別事例を調べる地図です。政府機関の公式サイトではありません。地点は住所の代表位置を含み、記録の分布は危険度を示しません。出典照合は転記・ファイル整合性の確認です。

## v1.2.0

- PCは左パネル内で検索・一覧・候補・詳細を操作。戻ると検索条件、一覧のスクロール、地図の表示範囲を復元します。
- スマホは地図の下に表示・色分け、絞り込み、一覧・詳細を配置。モーダルを使わず、重複地点は候補一覧から選択します。
- 操作・説明・凡例の本文を20px以上に統一。既存の地図見出しはPCで20px、スマホで16pxと測定し、大きい方を採用しました。
- 地理院の淡色・標準・写真・陰影起伏・色別標高図と今昔マップを選択。古地図は同一地図上の透過重ね合わせで比較します。
- 古地図の地域・年代・縮尺・図幅範囲と、地図中央の図幅の測量／発行履歴を表示します。
- 地形と陥没表示の不透明度・凡例を分け、英語切替・メッシュ・時系列再生・出典照合を維持します。
- 外部出典リンクはHTTP/HTTPSのみ許可し、不正なURLハッシュで初期表示が停止しないよう修正しました。既存のCSV式注入対策も維持しています。

## 地形比較の範囲

比較閲覧専用です。位置合わせ、標高基準、解像度、測量時期、誤差の整合を検証していないため、標高差の数値化と切土・盛土の自動判定は未対応です。等高線の外観だけで切土・盛土を断定できません。工事記録・測量図・現地情報で確認してください。

DEM由来の地形画像は国土地理院の配信タイルを使います。地点の標高値は表示しません。欠測・範囲外・読込失敗を別の標高や地図で埋めません。透過した現在地図は古地図が存在することを意味しません。

「現在」は現在配信される地図であり、当日の測量ではありません。写真・現在地図の地点ごとの取得日、標高基準と誤差は本サイトでは取得していません。歴史地図の日付は提供者の図歴表記を保持しています。

## ソース・検証・公開

配布ZIPの中に編集可能なHTML・CSS・JavaScriptとデータが含まれています。既存の配布リポジトリの構成を維持し、ZIPを src/ に展開して編集します。依存する地図ライブラリはvendor/に同梱しています。外部タイルにはネットワーク接続が必要です。

```
Expand-Archive -LiteralPath website-v1.2.0.zip -DestinationPath src
node scripts/check.cjs
node preview.cjs
```

プレビュー: http://127.0.0.1:8766/

テストではデータファイルの固定SHA-256、件数、年度・深さ・検索、メッシュ集計、時系列、外部リンク、HTML構造、古地図図幅、ドラッグ／複数指操作の選択抑制と戻る際の表示範囲の復元を確認します。ブラウザでの確認内容と未検証項目は QA-v1.2.0.md に記載しています。

公開対象は release.json で指定する website-vX.Y.Z.zip です。ZIP直下にindex.htmlを置き、SHA-256を記載します。mainへの反映後、既存GitHub Actionsがハッシュとnoindexを確認してPagesへ配信します。noindex, nofollowはアクセス制限ではありません。戻す場合はrelease.jsonを以前のアーカイブ名・SHA-256へ戻します。
